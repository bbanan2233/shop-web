## О проекте

SHIFT PC — учебный каталог компьютерных комплектующих. Сайт включает 13 статических HTML-страниц, шесть товаров с отдельными страницами, сравнение наборов и демонстрационную форму заявки.

Все модели, характеристики, контакты, цены и условия вымышлены. Сайт не принимает оплату и не создаёт реальные заказы. Иллюстрации комплектующих — собственные схематичные SVG; внешних изображений, шрифтов и библиотек нет.

## Просмотр на компьютере

1. Полностью распакуйте архив.
2. Откройте `index.html` в браузере. Страницы, стили и изображения используют относительные пути.
3. Для проверки формы предпочтителен локальный HTTP-сервер. При установленном Python откройте терминал в папке проекта и выполните:

```bash
python -m http.server 8000
```

На Windows при необходимости используйте `py -m http.server 8000`.
Откройте `http://localhost:8000`. Остановка сервера — `Ctrl+C`.

Установка npm-пакетов и сборка не нужны.

## Технологии

- HTML5: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, формы, таблицы, `details`, `dialog`.
- CSS: переменные в `:root`, Flexbox, Grid, базовый БЭМ, псевдоклассы, позиционирование.
- Минимальный JavaScript для модального окна, без библиотек и фреймворков.
- Git и подготовка к GitHub Pages.

## Где показаны обязательные приёмы

- На каждой странице один `main`, уникальные `title` и `meta description`, общие шапка, навигация, CSS и подвал.
- `article.product-card` — самостоятельная карточка товара; `aside.catalog-sidebar` — дополнительная панель каталога.
- Якоря: `index.html#popular`, `#advantages`, `#faq`, категории каталога, `#specifications`, `#top`.
- Таблицы содержат `caption`, `thead`, `tbody`, `th`, `td`; в сравнении есть `tfoot`.
- Поля формы связаны с `label` через `for`/`id`, имеют `name`; обязательные поля — `required`.
- `type="email"` проверяет формат почты; `pattern` проверяет телефон: `+7` и десять цифр без пробелов.
- Flexbox: меню, ряды кнопок, низ карточек, шапка и подвал.
- Grid: главный блок, каталог с боковой панелью, сетка товаров, страница товара и форма.
- БЭМ: `product-card__title`, `site-header__inner`, `site-nav__link--active`, `product-grid--catalog`.
- `relative`: карточка-изображение; `absolute`: бейдж; `sticky`: шапка и фильтры; `fixed`: кнопка «Наверх»; `z-index`: слои шапки, бейджа, кнопки.
- `:hover`, `:focus-visible`, `:disabled`, явное оформление отключённых фильтров.

## Самостоятельные доработки

1. Собственная визуальная концепция SHIFT PC: типографика, цветовые акценты и авторские SVG.
2. Шесть отдельных страниц товаров с характеристиками вместо одной демонстрационной модели.
3. Страница сравнения двух наборов с проверенными итогами: 62 500 ₽ и 122 400 ₽. Наборы не включают корпус и БП; базовый набор также не включает видеокарту.
4. Страница доставки и оплаты, FAQ на нативных `details`/`summary`.
5. Хлебные крошки, категории-якоря, связанные товары и фиксированная кнопка «Наверх».
6. Дополнительные параметры на карточках и разные бейджи.
7. Подсказки к форме, выбор способа связи, очистка, отдельная страница результата без ложного сообщения об отправке.
8. Ссылка пропуска меню, видимый фокус, подписи, `scope` для таблиц, управление модальным окном через браузер, учёт `prefers-reduced-motion`.
9. Простые медиазапросы для узких экранов. Полная адаптация может быть расширена в следующих КР.

## Поведение и ограничения

Форма использует HTML-проверку и `GET` на `thanks.html`. Данные оказываются в URL; приложения для хранения заявок, серверной обработки или отправки писем нет. На опубликованном сайте URL может попасть в журналы хостинга, поэтому **вводите только вымышленные данные**. `thanks.html` можно открыть напрямую — она не доказывает, что форма была заполнена.

Товар выбирается вручную в форме: автоматической передачи выбора из карточки нет. Это сохраняет JavaScript в пределах открытия/закрытия модального окна.

Фильтры каталога отключены и прямо помечены как статический макет. Категории работают как якорные ссылки. Корзина, авторизация, оплата, API и React не реализованы и для этой КР не требуются.

Общие шапка и подвал повторены в статических HTML-файлах. Для многостраничного проекта без сборщика это намеренное простое решение. Стили общие и не дублируются по страницам.
